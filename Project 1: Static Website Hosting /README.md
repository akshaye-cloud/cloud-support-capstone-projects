# AWS Static Website Hosting Capstone

## Project Overview

This project demonstrates hosting a static website using Amazon S3 and CloudFront.

## Architecture

- Amazon S3
- CloudFront CDN
- Static Website Hosting

## Features

- Static website hosting
- CDN acceleration
- Public access configuration
- Responsive web page

## AWS Services Used

- Amazon S3
- CloudFront
- IAM
